    Standing Rules

      With the server running, each board is one file in the boards folder. This page reads it fresh on load and writes back through the local server. Every save takes a timestamped backup first.

      Board

      Names new tickets. BM gives you BM-101. Existing keys never change.
      Clearing deletes every ticket and backlog item on this board and cannot be undone. Deleting removes the whole board and its tab. With the server running, a deleted board's file moves to boards/deleted/ and can be recovered. Export first if you want to keep a copy.

      Board columns

      Rename and reorder freely. The stored key behind each column never changes, so a rename cannot orphan a ticket or break its history. Removing a column makes you move its tickets first, and the ledger refuses the save if any are left behind.

      Column roles

      Where a backlog item goes when you send it to the board.
      Moving a ticket here stamps the done date and ticks every criterion. Pace, burndown and velocity all count this column.
      A display limit only. Older done tickets collapse behind a "Show all" button on the column; nothing is deleted, archived, or removed from the ledger. Burndown, velocity, pace and epic progress keep counting every done ticket. Set 0 to show them all.
      The Failed action is offered only while a ticket sits in the first column, and sends it to the second with a required reason. Set either to Off to remove the action.
